# 10: 完成今日概览与本地数据管理

**What to build:** 提供一个可信的今日概览，让使用者看到受限应用总用时、各应用额度、拦截次数和紧急解锁状态，并能管理只保存在本机的90天历史数据。

**Blocked by:** 07: 让放宽规则在次日生效; 08: 实现弱限制等待与使用窗口; 09: 实现强限制的紧急解锁

**Status:** ready-for-agent

- [ ] 今日概览显示全部受限应用的今日总用时。
- [ ] 每个受限应用显示限制等级、已用时间和剩余每日额度。
- [ ] 今日概览显示拦截次数以及今日紧急解锁是否已使用。
- [ ] 待生效变更在相关应用旁清晰可见。
- [ ] 核心权限失效时，概览优先显示保护失效并标明数据可能不完整。
- [ ] 使用、拦截和紧急解锁历史默认保留90天，过期记录按明确规则清理。
- [ ] 使用者可以从 OneSec 内清除全部本地数据，并在破坏性操作前明确确认。
- [ ] 清除后规则、历史、窗口、待生效变更和紧急解锁记录均不存在，界面回到真实的初始状态。
- [ ] 应用不申请联网权限，也不接入账户、分析、遥测或云同步。
- [ ] 自动化测试覆盖概览聚合、权限失效、90天保留边界和清除全部数据。
