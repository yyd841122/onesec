# 08: 实现弱限制等待与使用窗口

**What to build:** 让弱限制应用在每日额度耗尽后先要求使用者等待15秒，再提供一个5分钟使用窗口；窗口结束后重新拦截，从而为必要使用增加可控摩擦。

**Blocked by:** 05: 额度耗尽后执行强限制拦截

**Status:** completed

- [x] 使用者可以将应用设置为弱限制，默认每日额度为60分钟。
- [x] 每日额度以内打开弱限制应用时不显示等待页。
- [x] 每日额度耗尽后打开弱限制应用会显示15秒等待体验。
- [x] 等待完成前不能获得使用窗口，离开后重新进入不会错误跳过等待。
- [x] 等待完成后创建恰好5分钟的使用窗口，并允许打开目标应用。
- [x] 使用窗口有效期间不会重复要求等待。
- [x] 使用窗口到期后再次进入或继续使用目标应用会触发新的拦截决定。
- [x] 使用窗口状态在进程重建后保持正确，且不能因重启获得无限使用。
- [x] 限制决策模块测试使用可控时钟覆盖等待前、等待完成、窗口内、窗口边界和窗口到期。

## Comments

- 2026-08-21: 已实现弱限制设置、15秒等待、持久化5分钟使用窗口及到期重新拦截。JVM 测试与 19 个设备测试通过；lint 通过。
