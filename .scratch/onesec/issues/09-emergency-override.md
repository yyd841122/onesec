# 09: 实现强限制的紧急解锁

**What to build:** 为强限制提供一个不醒目的紧急入口。使用者每天最多一次，在等待60秒并填写原因后获得5分钟使用窗口；该机会和原因在本地可靠保存。

**Blocked by:** 05: 额度耗尽后执行强限制拦截

**Status:** completed

- [x] 强限制拦截页通过二级入口提供紧急解锁，不把它设计为默认操作。
- [x] 紧急解锁必须完成连续60秒等待。
- [x] 等待完成后仍需填写非空原因才能确认。
- [x] 成功后获得恰好5分钟的目标应用使用窗口。
- [x] 同一受限应用或其他强限制应用在同一本地自然日不能获得第二次紧急解锁。
- [x] 应用进程或手机重启不会重置当日紧急解锁状态。
- [x] 下一个本地自然日恢复一次新的紧急解锁机会。
- [x] 解锁原因、时间和结果只保存在本机。
- [x] 限制决策模块测试覆盖资格、等待、缺失原因、窗口有效期、每日次数和跨日重置。

## Comments

- 2026-08-21: 已实现每日一次紧急解锁、连续60秒等待、原因记录、持久化5分钟窗口和跨日恢复。JVM、lint 与真机测试通过。
