# 11: 完成 OPPO Reno 第一版验收

**What to build:** 将所有已完成的纵向能力作为一个真实产品流程在 OPPO Reno PCAM00 上验证，修复阻止第一版个人试用的问题，并建立14天试用记录，以判断 OneSec 是否真正减少过度使用。

**Blocked by:** 06: 重启后恢复保护并适配 ColorOS 后台运行; 07: 让放宽规则在次日生效; 08: 实现弱限制等待与使用窗口; 09: 实现强限制的紧急解锁; 10: 完成今日概览与本地数据管理

**Status:** ready-for-agent

- [ ] 在 Android 11 / ColorOS 11.1 的 PCAM00 上完成从授权、选应用、设额度、累计用时到拦截的完整流程。
- [ ] 真机验证强限制、弱限制等待、5分钟使用窗口和每日一次紧急解锁。
- [ ] 真机验证锁屏、切到后台、本地零点跨日和日期归属不会产生明显错误用量。
- [ ] 真机验证撤销每项核心权限时都能看到保护失效，并能按指引恢复。
- [ ] 真机物理重启后，规则、当日状态、待生效变更和监控均按规格恢复。
- [ ] 在 ColorOS 常规省电条件下观察后台存活，并记录必须由使用者完成的系统设置。
- [ ] 验证应用没有联网权限，敏感记录只保存在本机，清除全部数据功能有效。
- [ ] 修复所有会导致误拦截、无法返回桌面、保护静默失效或数据丢失的第一版阻塞问题。
- [ ] 建立14天试用日志，记录每日受限应用用时、误拦截、权限失效和紧急解锁次数。
- [ ] 明确试用成功标准：受限应用除显式使用窗口外不超过额度，不因误拦截关闭或卸载 OneSec，紧急解锁平均每周不超过两次。
