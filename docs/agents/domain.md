# Domain Docs

OneSec uses a single domain context.

## Before exploring

- Read the root `CONTEXT.md`.
- Read relevant decisions under `docs/adr/`.
- If either is absent, proceed silently.

## Vocabulary

Use the canonical terms defined in `CONTEXT.md`. Avoid synonyms that the glossary explicitly rejects.

If a required domain concept is missing, reconsider the wording or record the gap for `/domain-modeling`.

## ADR conflicts

If proposed work contradicts an existing ADR, identify the conflict explicitly instead of silently overriding the decision.
