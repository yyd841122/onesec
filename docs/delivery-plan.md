# OneSec 交付路线

## 里程碑 0：开发环境

- 检查 JDK、Android SDK、ADB 与 Gradle 环境。
- 创建 Kotlin + Jetpack Compose 工程。
- 使用临时包名 `com.example.onesec`。
- 在 OPPO Reno（PCAM00）上安装空壳应用。

完成标准：空壳应用可在测试机启动，基础单元测试可运行。

## 里程碑 1：核心纵向切片

- 引导并验证使用情况访问权限与无障碍权限。
- 列出已安装应用并选择一个受限应用。
- 保存单个应用的每日额度。
- 计算该应用当日前台使用时间。
- 额度耗尽时触发全屏拦截。
- 重启手机后恢复规则与检测。

完成标准：产品规格中的端到端验收场景在真实设备上通过。

## 里程碑 2：完整规则

- 支持强限制、弱限制和不限制三个等级。
- 实现待生效变更。
- 实现弱限制的等待与使用窗口。
- 实现强限制的每日一次紧急解锁。
- 记录拦截与紧急解锁历史。

## 里程碑 3：可靠性与概览

- 增加安静的持续通知。
- 完成 ColorOS 后台运行和电池优化引导。
- 正确处理锁屏、跨日、时区变化、重启和权限撤销。
- 完成今日概览及 90 天数据清理。
- 在真实设备上连续试用 14 天并记录结果。

## 里程碑 4：验证后的增强

- 最近七天趋势。
- 多设备与更多 Android 版本兼容测试。
- 评估应用内部区域识别。
- 评估签名 APK 和应用商店发布要求。

每个里程碑都应按一个可观察行为一个测试切片的方式实现，并在进入下一里程碑前审查实际差异与产品规格是否一致。
