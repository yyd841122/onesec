# OneSec

OneSec 是一款面向个人使用的 Android 自律工具，通过每日使用额度和分级限制，减少短视频与游戏的过度使用。

项目目前处于设计确认阶段。第一阶段只服务一台 OPPO Reno（PCAM00，Android 11 / ColorOS 11.1）测试机，并优先验证“统计用时 → 额度耗尽 → 拦截应用”这条完整链路。
